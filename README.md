# GenCut

GenCut is an AI customer-acquisition workforce for real-estate agents and brokers, starting in Miami / South Florida. It finds real opportunities in public property records, researches them, builds complete personalized campaigns with Film Crew media, and queues outreach for one-tap approval behind a compliance gate.
